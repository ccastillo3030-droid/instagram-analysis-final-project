**Instagram Accounts Analysis**

**CIT 5001: Python with Ethical AI**

**Project Description** 

This project analyzes the Most Followed Instagram Accounts dataset from Kaggle using Python and pandas.

The project answers the following questions:

Which Instagram accounts have the highest number of followers?
Which Instagram categories appear most often?
Which category has the highest average number of followers?

**Skills Demonstrated**

Python
Pandas
Data Filtering
Statistical Analysis
Data Visualization
Functions
Loops
Conditional Statements

**Dataset**

Most Followed Instagram Accounts Daily (Kaggle)

**Summary**

The analysis showed that Instagram, Cristiano Ronaldo, and Lionel Messi are among the most followed accounts. Sports was the most common category, while Fashion & Beauty accounts had the highest average follower counts.
